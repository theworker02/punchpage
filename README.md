# punchpage

Punch and reshape page text streams with deterministic transforms.

**Site:** https://theworker02.github.io/punchpage/

## Install / run

```bash
git clone https://github.com/theworker02/punchpage.git
cd punchpage
node src/cli.js
node --test
```
